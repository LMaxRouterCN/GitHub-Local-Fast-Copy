# GitHub-Local-Fast-Copy

不请求raw站点,而是从DOM中获取纯文本复制,解决了国内由于访问raw站点的网络延迟从而导致的复制失败问题

复制的文本和`Code`视图下的文本相同,所见即所得

## 📦 安装指南
1. 确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/) 扩展。
2. 点击油猴图标，进入“添加新脚本”。
3. 清空默认内容，将 `github-fast-copy.user.js` 中的全部代码粘贴进去。
4. 按 `Ctrl+S` (Mac: `Cmd+S`) 保存。
